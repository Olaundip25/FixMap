# FixMap

FixMap adalah aplikasi pelaporan fasilitas umum berbasis peta yang memungkinkan masyarakat melaporkan kerusakan infrastruktur seperti jalan berlubang, lampu jalan mati, trotoar rusak, saluran air tersumbat, dan fasilitas publik lainnya.

## Fitur Utama
- Pelaporan fasilitas umum berbasis lokasi
- Upload foto laporan
- Status laporan (Menunggu, Diproses, Selesai, Ditolak)
- Dashboard admin
- Peta interaktif laporan
- Filter kategori dan status
- Manajemen akun pengguna

## Teknologi
- React.js
- React Router
- TanStack Query
- Base44 SDK
- Tailwind CSS
- Lucide React

## Struktur Halaman
- Beranda
- Buat Laporan
- Laporan Saya
- Detail Laporan
- Dashboard Admin
- Login & Registrasi

## Cara Menjalankan
```bash
npm install
npm run dev
```

## Build Production
```bash
npm run build
```

## Lisensi
Proyek ini dibuat untuk kebutuhan pelaporan fasilitas umum dan pengembangan pembelajaran.
